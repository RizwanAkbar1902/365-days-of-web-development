\# Day 10 - CSS Flag Project



Today I practiced CSS by recreating the flag of Laos using only HTML and CSS.



The main focus of this exercise was positioning different elements correctly and understanding how nested elements can be selected without adding extra classes or IDs.



\## What I Practiced



\- `position: relative`

\- `position: absolute`

\- `top` and `left`

\- `transform: translate()`

\- `border-radius`

\- Width and height

\- Percentage values

\- Child selectors

\- CSS colors

\- Working with nested elements



\## What I Learned



The main thing I learned today was how `relative` and `absolute` positioning work together. I also practiced centering the white circle using `top`, `left`, and `transform`.
