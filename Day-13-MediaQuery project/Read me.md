\## 📖 Overview



The \*\*Agency Landing Page\*\* serves as a modern front-end layout project showcase. It features a high-impact heading section, dual feature cards ("Beauty" and "Construction") styled using standard float-based column layouts, responsive adjustments for mobile viewports, and a simple footer anchor.



\---



\## ✨ Key Features



\- \*\*Responsive Design:\*\* Adapts smoothly across viewports using media queries (breakpoint at `680px`).

\- \*\*Typography:\*\* Uses Google Fonts (\*\*Poppins\*\*) for clear, modern visual hierarchy.

\- \*\*Semantic HTML5:\*\* Clean document structure with appropriate semantic elements (`<header>`, `<main>`, `<footer>`).

\- \*\*Flexible Layout:\*\* Body flexbox container ensures footer remains positioned at the bottom.

\- \*\*Custom Styling:\*\* Muted off-white background (`#faf9f6`) paired with deep `midnightblue` accents.



\---



\## 🛠️ Tech Stack



\- \*\*HTML5\*\* - Structure and layout content

\- \*\*CSS3\*\* - Custom styling, CSS floats, and media queries

\- \*\*Google Fonts\*\* - Poppins (Weights: 400, 700)
