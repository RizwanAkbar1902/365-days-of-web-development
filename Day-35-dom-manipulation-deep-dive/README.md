# Day 35: The Document Object Model (DOM)

Comprehensive practice covering DOM element selection, class list manipulation, content updating, and HTML attribute management.

### Key Learnings
- Element Selectors: `getElementById`, `getElementsByClassName`, `querySelector`, and `querySelectorAll`.
- Separation of Concerns: Modifying appearance by toggling CSS classes via `classList.add()` rather than direct inline styles.
- Text & HTML Manipulation: Comparing raw text updates using `textContent` versus HTML injection with `innerHTML`.
- Attribute Control: Reading and mutating element attributes using `getAttribute()` and `setAttribute()`.

### How to Run
Open `index.html` in your browser and check the updated DOM elements and browser console.
