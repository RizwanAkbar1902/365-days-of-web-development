# Day 27: JavaScript Function Outputs & BMI Calculator

Completed exercises on function output values, the `return` statement, and mathematical modeling using the BMI formula.

### Topics Covered:
* **Function Outputs:** Returning computed values using the `return` keyword instead of purely printing to the console.
* **Math Utilities:** Utilizing `Math.pow()` for exponents and `Math.round()` to get rounded integer results.
* **BMI Calculator Challenge:** Implemented metric BMI logic (`weight / (height * height)`) accepting dynamic weight (kg) and height (m) arguments.

### Execution:
* Run in terminal: `node script.js`
* Or open `index.html` in browser and check the developer console.
