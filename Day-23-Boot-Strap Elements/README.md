\# Move It — Bootstrap 5 Components Landing Page



A complete multi-section landing page built to practice combining core Bootstrap 5 UI components into a cohesive, responsive webpage.



\### Components Implemented:

\* \*\*Responsive Navbar:\*\* Built using `.navbar`, collapse navigation menu, dropdown menu, and an inline search form.

\* \*\*Hero Banner:\*\* Centered call-to-action layout using `display-4`, button groups, and fluid responsive image containers.

\* \*\*Feature Grid:\*\* 3-column feature section using `row-cols-1 row-cols-lg-3`, custom gradient icon badges, and icon links.

\* \*\*Interactive Carousel:\*\* Image slider with indicators, slide transitions, and next/previous controls powered by Bootstrap JS Bundle.

\* \*\*Multi-column Footer:\*\* Responsive grid footer with brand info and categorized navigation links.



\### Tech Stack:

\* Semantic HTML5

\* Bootstrap 5.3 (via CDN)

\* SVG vector assets
