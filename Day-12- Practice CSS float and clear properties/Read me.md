\# Day 11 - CSS Float and Clear



\## About This Project



Today I practiced the CSS `float` and `clear` properties by building a simple Pet World Journal page.



I created separate sections for cats and dogs and used float to place them on opposite sides of the page. I also used float on the images so that the text could wrap around them.



\## What I Practiced



\- CSS `float`

\- CSS `clear`

\- Two-column layout

\- Text wrapping around images

\- Width and spacing

\- Margins and padding

\- Borders and border-radius

\- Box shadows

\- Basic page styling



\## What I Learned



The main thing I learned today was how the `float` property affects the position of elements and how text can flow around a floated image.



I also learned why `clear: both` is useful when working with floated elements, especially when placing content below them.
