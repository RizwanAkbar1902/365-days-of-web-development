\# CSS Layout Reference (Flexbox vs Grid)



A quick side-by-side comparison page I built to revise 1D vs 2D CSS layout behavior.



\### What it covers:

\* \*\*Flexbox:\*\* 1-dimensional distribution, axis alignment, and auto-spacing using `justify-content` and `gap`.

\* \*\*CSS Grid:\*\* 2-dimensional track sizing with `repeat()`, `fr` units, and explicit column spanning (`grid-column: span`).



\### Files:

\* `index.html` - Combined markup, CSS styles, and visual demo cards.



Built purely with semantic HTML5 and vanilla CSS.
