# Day 27: JavaScript ES6 Basics & Variables Exercise

Completed foundational JavaScript modules covering browser alerts, primitive data types, variable declarations, and the classic variable swapping exercise.

### Topics Covered:
* **Browser Alerts:** Adding interactive user prompts and behavioral triggers using `alert()`.
* **Data Types:** Working with Strings, Numbers, Booleans, `undefined`, and `null`.
* **Variable Operations:** Storing, accessing, and mutating state in memory.
* **Variable Swapping Exercise:** Solved the classic value swap challenge using temporary variable storage logic (`c = a; a = b; b = c;`).

### How to Test:
