\# Bootstrap 5 Basics: Grid \& Cards



Practiced Bootstrap 5 fundamentals today, focusing on setting up via CDN, understanding the 12-column layout, and using pre-built card components.



\### What I built \& practiced:

\- Linked Bootstrap 5 using official CDN.

\- Created a responsive 3-card layout using `.container`, `.row`, and `.col-\*` classes.

\- Used `col-12 col-md-4` so cards take full width on mobile screens and divide evenly into 3 columns on larger screens (4 columns each out of 12).

\- Styled cards using Bootstrap classes (`.card`, `.card-body`, `.card-title`, `.btn`).

\- Handled spacing and vertical alignment using grid gap (`g-4`) and `h-100`.



\### Structure:

\- `index.html` - HTML markup with Bootstrap CDN links and responsive card grid.
