# Day 28: JavaScript Strings, Arithmetic & Functions

Explored core string methods, arithmetic logic, and functional programming foundations in JavaScript ES6.

### Topics Covered:
* **String Mechanics:** Length checking (`.length`), extraction (`.slice()`), and case conversions (`.toUpperCase()`, `.toLowerCase()`).
* **Name Capitalization Challenge:** Solved string slicing logic to normalize mixed-case user input.
* **Math & Operators:** Modulo (`%`) for remainders, increment/decrement (`++`, `--`), and order of operations.
* **Functions:** Creating, invoking, and passing dynamic parameters and arguments.

### Running the Code:
* **Terminal:** Run `node script.js`
* **Browser:** Open `index.html` and inspect the browser console.
