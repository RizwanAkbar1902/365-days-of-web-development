# Day 31: JavaScript Arrays & Collections

Explored fundamentals of JavaScript arrays, list handling, and checking element presence.

### Concepts Covered:
* **Array Definition:** Creating zero-indexed ordered collections.
* **Length Property:** Retrieving element counts using `.length`.
* **Membership Check:** Using the ES6 `.includes()` method for conditional lookups.
* **Modifying Collections:** Appending elements dynamically using `.push()`.
