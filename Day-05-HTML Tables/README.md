\# Day 05 HTML Tables \& Layout Practice



A structured practice file exploring HTML table elements, cell merging properties, and legacy layout structuring.



\### Concepts Covered:

\* \*\*Core Table Structure:\*\* `<table>`, `<tr>`, `<th>`, and `<td>` tags.

\* \*\*Semantic Grouping:\*\* Organized tables using `<thead>` and `<tbody>` sections.

\* \*\*Cell Merging:\*\* Demonstrated horizontal spanning (`colspan`) and vertical spanning (`rowspan`).

\* \*\*Table Layouts:\*\* Built a basic CV profile card using table cells and attributes (`cellpadding`, `valign`, `align`).



\### Files:

\* `index.html` - Complete HTML markup demonstrating table structures.
