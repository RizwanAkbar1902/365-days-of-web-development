\# 🚀 Responsive CSS Grid Layout Showcase



A clean, modern, and fully responsive layout built using pure HTML5 and CSS Grid. This project demonstrates advanced CSS Grid techniques including explicit/implicit grids, fractional units (`fr`), fractional spanning, and responsive design using `repeat()`, `auto-fit`, and `minmax()`.



\## ✨ Features

\- \*\*Responsive without heavy media queries:\*\* Uses `repeat(auto-fit, minmax(250px, 1fr))` for fluid layouts across device widths.

\- \*\*Asymmetric Grid Spanning:\*\* Utilizes `grid-column: span 2` and `grid-row: span 2` for featured content highlights.

\- \*\*Pure CSS \& HTML:\*\* Clean, modular, and modern styling practices.



\## 🛠️ Concepts Applied

\- CSS Display Grid (`display: grid`)

\- `grid-template-columns` \& `gap`

\- Column \& Row Spanning (`grid-column`, `grid-row`)

\- Fractional Units (`1fr`) \& `minmax()` logic
