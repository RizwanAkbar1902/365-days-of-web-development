\# Birthday Invite Project



A simple HTML project created to practice core markup tags by building a birthday party invitation page.



\### Features \& Elements Used:

\* \*\*Headings:\*\* Structured page content using `<h1>`, `<h2>`, and `<h3>` tags.

\* \*\*Image Embedding:\*\* Integrated an external image with `<img>` and proper `alt` text.

\* \*\*Unordered List:\*\* Outlined items to bring using `<ul>` and `<li>` elements.

\* \*\*Hyperlinks:\*\* Added an anchor tag (`<a>`) linking to a Google Maps party location.



\### Files:

\* `index.html` - Complete semantic HTML markup for the invite.
