\# Flexbox Pricing Table



\## About



Today I practiced CSS Flexbox by creating a simple pricing table with three different plans: Basic, Standard, and Premium.



The main goal of this project was to understand how Flexbox can be used to arrange elements in a row and how the layout can change on smaller screens.



\## What I Practiced



\- `display: flex`

\- `justify-content`

\- `flex-direction`

\- `align-items`

\- Flexbox layout

\- Media queries

\- Responsive design

\- CSS spacing

\- Basic styling



\## What I Learned



I learned how Flexbox can make it easier to arrange multiple elements on a webpage. I also practiced changing the layout from a row to a column using a media query for smaller screens.
